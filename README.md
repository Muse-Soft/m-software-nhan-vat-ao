# Nhân Vật Ảo — Website giới thiệu nhân vật ảo 3D

Website giới thiệu một nhân vật ảo 3D phong cách tướng Việt Nam thời đại mới: mặt sẹo, góc cạnh, bặm trợn, với hiệu ứng chuyển động 3D mô phỏng bằng CSS/JS trên trang tĩnh.

> Lưu ý: đây là bản demo với dữ liệu và hình ảnh mẫu. Nhân vật là nhân vật hư cấu, không phải người thật.

## Xem trực tuyến

- Demo: https://m-software-nhan-vat-ao.genalpha.dev

## Cách xem / chạy

Mở file `index.html` bằng trình duyệt bất kỳ, hoặc truy cập link demo ở trên. Không cần cài đặt thêm.

## English summary

A static showcase website for a fictional 3D virtual character in the style of a modern-era Vietnamese general: scarred face, angular features, bold presence, with simulated 3D motion effects.
